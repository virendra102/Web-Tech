Css Selectors

1. Simple Selectors

You can select elements in four different ways:id, class, tagname, universal selector. 1. Id selector: uses # followed by the id of the element.
2. Class selector: uses . followed by the class name of the element.
3. Tagname selector: uses the name of the tag directly.
4. Universal selector: uses * to select all elements.
