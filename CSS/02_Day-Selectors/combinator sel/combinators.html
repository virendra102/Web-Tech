2. Combinators Selectors


Combination of two or more html elements to select a specific element is called combinators selectors. There are four types of combinators selectors in CSS. They are:
1. Descendant Combinator(space)
2. Child Combinator(>)
3. Adjacent Sibling Combinator(+)
4. General Sibling Combinator(~)

5. Grouping Selector(,)
